# Java AQA Homework

Репозиторий с домашними заданиями по курсу AQA.

## Технологии

- Java 25 (LTS)
- IntelliJ IDEA
- Git

## Домашние задания

| № | Задание | Статус |
|---|---|---|
| 1 | Разбор лога прогона тестов | В процессе |

## Структура проекта

Каждое домашнее задание находится в отдельном пакете `taskN` внутри `src`.

Для каждого задания создаётся отдельная Git-ветка. После завершения и проверки задания изменения объединяются с `main`.
