
# Java AQA Practice

Практические задания по курсу автоматизированного тестирования на Java (AQA).

## Практические задания

| № | Задание | Статус |
|---|---|---|
| 1 | Разбор лога прогона тестов | Выполнено |
| 2 | Как JUnit находит @Test | Выполнено |
| 3 | Ищем flaky-тесты | Выполнено |
| 4 | Сводка прогона стримами | Выполнено |

### Практика 1. Разбор лога прогона тестов

Консольное приложение для обработки результатов выполнения автоматизированных тестов.

**Дополнительное задание:** `SimpleStringBuilder` с возможностью отмены изменений.

### Практика 2. Как JUnit находит @Test

Реализация механизма поиска методов с пользовательской аннотацией `@TestId` с использованием Reflection API.

Формирование и сортировка плана тестирования по порядку выполнения.

**Проверка:** класс `EmptyChecklist` используется для проверки случая, когда отсутствуют методы с аннотацией `@TestId`.

### Практика 3. Ищем flaky-тесты

Поиск нестабильных тестов путём сравнения результатов двух прогонов с использованием множеств (`Set`).

Подсчёт количества тестов по статусам через `Map.merge()`.

**Дополнительное задание:** универсальный метод частотного анализа элементов массива с использованием обобщений (`Generics`).

### Практика 4. Сводка прогона стримами

Формирование отчёта о результатах тестирования с использованием Stream API.

Группировка тестов по статусам, поиск трёх самых долгих тестов и вычисление среднего времени прошедших тестов.

**Дополнительное задание:** поиск общих рабочих дней сотрудников с использованием `flatMap()`, `groupingBy()` и `counting()`.
